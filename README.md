# 📍 Where to Go (Куди піти?)

**Where to Go** — вебзастосунок на Django для швидкого вибору місць відпочинку, перегляду каталогу та додавання власних локацій з деталями, оцінками та відгуками.

Проєкт використовує сесії (`request.session`) для збереження даних користувача без необхідності складної реєстрації.

---

## ⚙️ Повний цикл запуску проєкту (Local Setup)

### 1 Клонування репозиторію

Отримайте локальну копію проєкту з GitHub:

git clone [https://github.com/polinakostiuk/Where_to_go.git]

### 2 Застосування міграцій (створення db.sqlite3 та системних таблиць)

python3 manage.py migrate

### 3 Запуск вебсервера розробки

python3 manage.py runserver

### 4 Відкриття у браузері

[http://127.0.0.1:8000/]
